## What has been verified historically

- Main rowwise accuracy: six models, six datasets, five methods and seeds 42–46; 900 seed results. Full layer sets contain 8,040 layer–seed units per method. Each method selects its own layer from its train-only candidate's outer-validation accuracy, breaking exact ties at the lowest layer. Layer-average scores use the full fixed layer set. Five methods share persisted splits and embedding identities. Llama-3.3-70B was deferred by the author.
- Grouped sensitivity: six models, CounterFact grouped by subject, Cities grouped by city, three methods and five seeds; 180 separate runs and 60 group-disjoint splits. This is not a five-method grouped experiment.
- Directional robustness: the final plotted subset has three models, six datasets, 768 layers and 20 perturbations per layer for five methods. Fixed-reg has 15,360 saved directions and 145,920 within-layer cosine pairs. Sixteen final fits reach the original iteration limit and remain in all denominators. Historical perturbation indices are not sufficiently preserved to certify exact paired realizations across methods. xRFM retains its historical standardized-space AGOP coordinate; the other methods' displayed directions are raw, without intercepts.
- New CAA/Fixed-reg CPU timing: 16,080 native records, 360 seed–method runs and 72 setting points were independently checked. The scientific producer is `a699dcf5f071067ca040f245727340662bd98098`; operational wrapper producer is `9009b0ccf855c2999e048e9139b8f3f3185e2d70`; integration is `842ac5993d30ab1575766b206e54423dadb30d0e`. CAA is the mean-difference midpoint readout, without regression. Fixed-reg preserves native candidate fitting and refitting, without regularization search.

Historical scientific integration `68faa5f84ce7b6a09c4f18fdd55b45156b219a1d` is a reusable code baseline, not the producer of every result. Original three-method accuracy records identify `ddf1437e2f71e3b50d63342fcabe24d8894add25` with source SHA256 `70d16be75141994d012c0ad2318a69df8c0a6974c393c6900f87bd07ed1b0531`. ## Computational-cost source boundary

The published five-method figure combines three older methods recovered from the original vector figure with the new CAA/Fixed-reg CPU1 records. It is not the output of the new unified five-method runner. Raw historical clocks, effective threads, seed aggregation and allocations for those original three series are not established by the recovered figure. The author confirmed that hardware and procedure had not changed; this author statement is retained separately from what logs demonstrate.

A later independent three-method CPU1 run used producer `afff33694106c31159e094d2061f9296788e2d1c`. Its latest available owner snapshot, 6 November 2026 02:30 UTC, reports 21,804/24,120 verified method records, 87/108 complete setting–method points and 28/36 complete three-method settings. Final export and final independent acceptance were still pending. This incomplete run is not used to fill a new run or to retroactively certify the published mixed-source figure.

New execution must prepare its own splits, candidate decisions and run identity. It must use the same declared native scientific budgets, complete layer sets and explicit timing boundaries. Successful synthetic tests demonstrate execution and bookkeeping; they do not establish full-grid completion or a real hardware speed ranking. New results must use a separate output root.

## Scientific mismatches that remain visible

The public paper retains the original steering control statistics and the original four-metric 1–10 external judge table. The newer four-method generation and six-metric 1–5 judge are not in public v4 and are optional workflows. Neither replaces the original steering results.

The exact original control-table producer and its per-step alpha/probability traces were not located. The new generation records likewise lack the trajectories needed to recompute those old metrics. The original control values are therefore provided as reported values, not as independently regenerated summaries. The retained legacy generation convention computes probability from a normalized direction and global bias; the optional calibrated path uses each method's own raw weight and bias. The paper's raw affine-logit formula does not establish that the unknown old control-table execution used that calibrated path.

The old four-metric judge's individual scores, precise exclusion decisions and exact judging transcript were not located. Its 300 cases, 265 evaluable cases and 160 fully valid pairs are published claims, not counts certified by this release's new score-import tool. An older two-metric Joyfulness/Coherence evaluator is not its producer and is removed from the release interface.

The separability implementation fits on all cached rows. The paper describes a training-set diagnostic, but the historical table does not identify its model, subset indices, producer or raw summary. The release preserves and labels the actual in-sample computation; it does not silently introduce a new split and claim the same 152/168 and 144/168 results.

The structure diagnostic is a cross-fitted plug-in calculation, not the main accuracy experiment or a numerical solution of the Gaussian fixed-point equations. Its legacy `delta` field means `p/n`, while the paper uses `n/p`; the release adds an explicitly named `aspect_ratio_n_over_p` field. With sklearn's sum-loss `C` convention, the equivalent mean-loss ridge strength is `1/(n*C)`, so the old table's `1/C` labels should be read as inverse-C labels. The historical six training fractions and exact flags were not recovered. The release declares a fresh configurable six-fraction grid and marks its provenance accordingly. Selecting the highest correlation across C is an exploratory descriptive summary, not an independent held-out validation of the selected correlation.

No separate numerical-theory experiment or fixed-point solver appears in public v4. The analytic derivation is not reclassified as an unimplemented computational experiment.

## Optional generation and judging provenance

Existing optional generation covers 9,000 outputs: Original, RAPTOR, GCS, Fixed-reg and CAA-style, 1,800 each. Pairing uses model, task, direction, prompt ID and the full generation seed. Original is an unsteered reference; it is not Fixed-reg. CAA-style generation uses native scalar-logistic calibration with epsilon `1e-6` and GCAV, distinct from midpoint accuracy and raw-mean robustness. xRFM steering was not performed.

Historical six-metric scores came from GPT-6.1 Terra shared conversations followed by a targeted GPT-6.1 Sol correction overlay. They are not a homogeneous single-API run, independent contexts, a fresh full rerating or external factual gold. Target/overall valid denominators are 1,670/1,614/1,672/1,476 for RAPTOR/GCS/Fixed-reg/CAA-style; 768 target/overall entries remain N/A. Content/preservation dimensions share 1,766 valid references per method. The optional equal-weight composite used 1,252/1,800 common complete pairs and is post hoc and descriptive. A new API run records its own actual endpoint, model, requests, responses and identity; it cannot inherit these historical provenance claims.

Raw generated text, prompts derived from third-party datasets, complete internal manifests, logs and activation caches are not included merely because they supported an experiment. Their provenance and redistribution rights require separate checks. Numeric reported values and reproducible preparation instructions preserve the distinction between reading published results and rerunning an experiment.
