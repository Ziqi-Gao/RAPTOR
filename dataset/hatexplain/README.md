# HateXplain loader reference

RAPTOR retains the historical Hugging Face HateXplain builder in
[`hatexplain.py`](hatexplain.py), with its original copyright attribution to the
Hugging Face Datasets authors and dataset-script contributor. Its Apache-2.0
license is preserved in
[`third_party/licenses/Apache-2.0.txt`](../../third_party/licenses/Apache-2.0.txt).

HateXplain is the dataset introduced by Binny Mathew, Punyajoy Saha, Seid Muhie
Yimam, Chris Biemann, Pawan Goyal, and Animesh Mukherjee. Consult the
[upstream dataset repository](https://github.com/hate-alert/HateXplain),
[original Hugging Face dataset card](https://huggingface.co/datasets/Hate-speech-CNERG/hatexplain/blob/main/README.md),
and [dataset paper](https://arxiv.org/abs/2012.10289) for attribution and source
information.

This project-authored pointer replaces the copied dataset card. No raw posts or
data samples are included here. Dataset redistribution terms are separate from
the builder's code license and remain unresolved for this release. See
[`docs/data.md`](../../docs/data.md) for lawful acquisition pointers, exact
RAPTOR preparation, row ordering, label mapping, and access limitations.
